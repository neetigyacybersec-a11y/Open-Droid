## What I do
- Write test plans with scenarios and success criteria.
- Choose metrics: task success rate, time-on-task, error rate, SUS, SEQ.
- Run moderated/unmoderated tests; analyze with ~5 users per iteration.
- Report findings with severity and recommendations.

## When to use me
Use during validation phase.

## Anti-patterns
- Testing too late; no metrics; biased tasks.
